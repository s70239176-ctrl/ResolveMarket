# Demo Market Seeds

Create these from `/admin` after deployment. Keep deadlines in the future for staking demos, then create one short-deadline copy for resolution demos.

1. Sports result
   - Question: Did Team A beat Team B in the listed match?
   - Source name: ESPN Match Center or BBC Sport
   - Source URL: Use the public match result page.
   - Yes label: Team A
   - No label: Team B

2. Official announcement
   - Question: Has the GenLayer team announced the next public testnet milestone on the official page?
   - Source name: GenLayer Blog
   - Source URL: https://www.genlayer.com/blog
   - Yes label: Announced
   - No label: Not announced

3. Clearly unresolved
   - Question: Has the next scheduled Olympic opening ceremony already finished?
   - Source name: Olympics
   - Source URL: Use the official event page.
   - Yes label: Finished
   - No label: Not finished
